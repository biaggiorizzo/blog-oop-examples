This repository contains Java code examples used in my blog posts about **Object-Oriented Programming (OOP)**.  
Each folder demonstrates a specific **OOP concept**, such as **abstraction, inheritance, encapsulation, polymorphism**, and more.

The goal is to help readers **visualize OOP principles through practical code** — all examples are simple, self-contained, and ready to run in any Java IDE.

> 💡 All examples are compatible with **Java 17+**.

---

## 🧩 Repository Structure

| Folder | Concept | Description |
|---------|----------|-------------|
| [`interfaces_example`](java/src/interface_example/Main.java) | **Interfaces & Implementation** | Demonstrates how to define and implement interfaces in Java. |
| [`inheritance_polymorphism`](java/src/inheritance_polymorphism/Main.java) | **Inheritance & Polymorphism** | Shows how subclasses inherit and override behavior from a base class. |
| [`abstraction_example`](java/src/abstraction_example/Main.java) | **Abstraction with Abstract Classes** | Illustrates how abstract classes define shared structure and behavior. |
